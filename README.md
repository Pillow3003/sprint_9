# Foodgram Test Automation

Этот проект содержит автоматизированные тесты для проверки функциональности сайта Foodgram. Тесты выполнены на базе Selenium и pytest и предназначены для проверки создания аккаунта, авторизации, создания рецептов и их отображения.

---

## Структура проекта

- **pages/** — папка с Page Object моделями:
  - `main_page.py` — страницы главной страницы, в которой реализованы методы создания аккаунта и входа.
  - `base_page.py` — базовая страница с общими методами.
  - `recipe_page.py` — страница рецептов с методами создания рецепта.

- **data.py** — файл с тестовыми данными и константами, такими как URL, текстовые строки и параметры рецептов.

- **tests/** — папка с тестовыми сценариями:
  - `test_main_page.py` — тесты по работе с главной страницей.
  - `test_recipe_page.py` — тесты по созданию и отображению рецептов.

- **conftest.py** — настройки Fixtures для WebDriver и авторизации.
